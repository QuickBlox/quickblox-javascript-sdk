QuickBlox JS SDK — Quickstart

Complete SDK workflow in a single click. Press Run to execute all 8 steps:

  1. Initialize SDK with app credentials
  2. Create application session (get auth token)
  3. Login user (authenticate with login/password)
  4. Connect to chat server (XMPP over WebSocket)
  5. Retrieve dialog list (up to 10, sorted by last message)
  6. Retrieve last 5 messages from the first dialog
  7. Send a test message to the first dialog
  8. Disconnect from chat
