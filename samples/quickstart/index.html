QuickBlox JS SDK — Quickstart Examples

basic.html — Standard Init

Full SDK workflow: init with credentials → create session → login → connect to chat → load dialogs → load messages → send message → disconnect.

token-based.html — Token-based Init

Two independent SDK instances. Instance A creates a session and gets a token. Instance B initializes with that token only (no authKey/authSecret) — simulates backend→frontend token handoff.

How to run

  1. Open basic.html or token-based.html in a text editor
  2. Fill in the CREDS object with your QuickBlox app credentials: 
    var CREDS = {
    appId: 12345,                  // Dashboard → Overview
    authKey: 'your_auth_key',      // Dashboard → Overview
    authSecret: 'your_auth_secret',// Dashboard → Overview
    accountKey: 'your_account_key' // Dashboard → Account Settings
};
  3. Fill in the USER object with a test user (create one in Dashboard → Users): 
    var USER = { login: 'testuser', password: 'testpassword' };
  4. Save the file
  5. Open the file in a browser (Chrome, Firefox, Edge)
  6. Open the browser Developer Console (F12 → Console tab) to see the full SDK debug log
  7. Click the Run button and watch the output

What you need

  1. A QuickBlox account — admin.quickblox.com
  2. An application created in the Dashboard
  3. At least one user created in Dashboard → Users
  4. At least one dialog (chat) — create via Dashboard or the Chat sample
