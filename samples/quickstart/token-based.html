QuickBlox JS SDK — Token-based Init Quickstart

Demonstrates two independent SDK instances and session token sharing. Press Run to execute all steps:

  1. Create SDK instance A (via new QB.QuickBlox())
  2. Initialize instance A with app credentials (appId, authKey, authSecret)
  3. Create session + login user on instance A (get session token)
  4. Create SDK instance B (independent copy)
  5. Initialize instance B with the token from instance A (no authKey/authSecret needed)
  6. Use instance B: retrieve dialogs, load messages (proves token works)
  7. Connect instance B to chat, send a test message
  8. Disconnect both instances
